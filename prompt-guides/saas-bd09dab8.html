SaaS — How to Use

Why this folder exists

This folder contains SaaS/product-interface design and audit prompts plus shared reference material for visual standards and implementation guidance.

Files in this folder

  • audit prompt latest.txt — use for the broad audit scope and output process described in that prompt.
  • Skills_File_Updated.txt — supporting SaaS/web design reference rules and guidance.

When to use this folder

Use these files when creating or reviewing a SaaS interface and you need the particular design or audit process defined by the chosen prompt. For a strictly component-by-component visual audit, also check Audit prompts/ and use the component-specific audit prompt and shared component rules where appropriate.

Recommended process

  1. Decide whether the task is to create/design an interface or audit an existing one.
  2. Read the chosen prompt's purpose, boundaries, and required output format before starting.
  3. Provide the relevant application URL or rendered prototype, screenshots, user/task context, requirements, and reference documents.
  4. Attach Skills_File_Updated.txt when its rules are relevant to the task and accessible to the AI tool.
  5. Ask the AI to follow the selected prompt's exact scope and output requirements.
  6. For an audit, require observable evidence and distinguish confirmed issues from recommendations or assumptions.
  7. Verify the resulting interface or report against the original requirements.

Expected output

The output specified by the chosen prompt. The skills file is supporting guidance and should not replace the task-specific prompt.

Important notes

  • This folder guide does not override the original prompt's constraints.
  • If a referenced source or report template cannot be accessed, provide it directly or record the limitation.
  • Avoid mixing broad UX findings with a narrowly scoped visual/component audit unless the selected prompt explicitly calls for both.
