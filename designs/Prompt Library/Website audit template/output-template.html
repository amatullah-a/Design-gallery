Scope & evidence

Audit basis

This report applies the evaluation parameters supplied in the uploaded design-evaluation prompt. It covers design-system consistency, UI quality, components, layout, UX, accessibility, mobile, functionality, performance and Irish-school content considerations.

Evidence rule: findings are based on the live beta pages accessible during review plus the site's published accessibility/privacy/cookie statements. Where the accessible crawl could not verify a visual or interactive property (for example exact CSS sizes, hover states or Core Web Vitals), the report marks it as unverified rather than presenting it as a confirmed defect.

  • Mobile, interaction-state and performance items requiring a browser runtime are explicitly marked for verification.
