# Website Audits — Usage Guide

## Purpose
Use the website evaluation prompt in this folder with the supplied HTML output template to produce an audit report in the template's format.

## Files to Attach

### `design-evaluation-prompt.txt` — Evaluation Instructions
Attach this file to tell the AI what evaluation to perform and which instructions to follow.

### `ccbs_beta_uiux_audit (1).html` — HTML Output Template
Attach the provided HTML report file alongside the evaluation prompt. Use it as the reference for the final report's structure and presentation.

The evaluation prompt defines the audit task; the HTML file provides the report template.

## How to Use These Files
1. Attach `design-evaluation-prompt.txt`.
2. Attach `ccbs_beta_uiux_audit (1).html` in the same request.
3. Provide the website URL or relevant materials needed for the evaluation.
4. Ask the AI to follow the evaluation prompt and use the supplied HTML file as the output template.
5. Request the completed report in HTML format, following the template's structure.

## Expected Output
A completed HTML audit report based on the evaluation prompt and structured according to the supplied template.

## Important
Always attach both files together. Do not use the evaluation prompt alone when the task requires the supplied HTML report format.
